* ###### 2\. Giới thiệu
* ###### Dự án được thực hiện nhằm xây dựng một website thương mại điện tử chuyên kinh doanh linh kiện điện tử, giúp khách hàng dễ dàng tìm kiếm, tham khảo thông tin, lựa chọn và đặt mua các sản phẩm linh kiện điện tử trực tuyến.

* ###### 3\. Mục tiêu

* ###### Đối với khách hàng:
* ###### Cung cấp công cụ tìm kiếm linh kiện điện tử nhanh chóng.
* ###### Xem thông tin chi tiết sản phẩm, hình ảnh, giá bán.
* ###### Phân loại và lọc sản phẩm theo danh mục.
* ###### Đăng ký, đăng nhập và quản lý tài khoản cá nhân.
* ###### Thêm sản phẩm vào giỏ hàng và đặt hàng trực tuyến.
* ###### Theo dõi tình trạng đơn hàng.

* ###### Đối với quản trị viên:
* ###### Quản lý danh mục linh kiện điện tử.
* ###### Thêm, sửa, xóa và cập nhật thông tin sản phẩm.
* ###### Quản lý tài khoản khách hàng.
* ###### Quản lý đơn hàng
* ###### Theo dõi số lượng tồn kho
* ###### Về kỹ thuật:
* ###### Áp dụng mô hình MVC (Model-View-Controller) để xây dựng ứng dụng web có cấu trúc rõ ràng, dễ bảo trì, nâng cấp và mở rộng trong tương lai.

**Hướng dẫn cài đặt và chạy chương trình**
Bước 1: Tải source code trên github
Bước 2: Mở bằng Visual Studio
Bước 3: Cấu hình database
Import file .sql trong thư mục database
Cập nhật connection string trong web.config (đổi tên theo server name để chạy thành công)
Bước 4: Chạy hệ thống
Nhấn Run (F5)
